## Phase Goal

**As a** wallet owner, **I want to** create, configure, and monitor my mint via a management SPA, **so that** I can manage my per-wallet mint instance without direct API calls — setting fees, limits, sunset mode, verify toggle, and viewing outstanding notes and activity.

## Acceptance Criteria

- [ ] The management SPA at `/lnurlmint/` displays a list of the wallet's mints with username, id, and status.
- [ ] A "Create Mint" dialog collects all config fields (username, base_fee_msat, fee_percent_ppm, min_sendable_msat, max_sendable_msat, min_mint_msat, verify_enabled, sunset_mint, base_url, onion_url) and creates a mint via POST.
- [ ] An "Edit" action opens a dialog pre-filled with the mint's current config and submits a PUT request for partial updates.
- [ ] A "Delete" action sends a DELETE request and shows a user-friendly error if 409 (outstanding notes).
- [ ] Each mint row can expand to show outstanding notes (id truncated, amount in sats, state, created_at).
- [ ] Each mint row can expand to show recent activity (type: mint/melt, amount, payment_hash truncated, timestamp).
- [ ] `GET /api/v1/mints/{mint_id}/notes` returns wallet-scoped outstanding notes (404 if mint belongs to another wallet).
- [ ] `GET /api/v1/mints/{mint_id}/activity` returns wallet-scoped recent activity (404 if mint belongs to another wallet).
- [ ] The SPA uses `LNbits.api.request` with the wallet's admin/invoice key for all API calls.
- [ ] The SPA is served via the `index` generic view with `check_user_exists` (authenticated).

## Artifacts This Phase Produces

This plan replaces the Phase 1 placeholder Vue page with a full management SPA
and adds two new API endpoints (outstanding notes + activity log). The SPA
follows the giftcards pattern: Vue 3 + Quasar SFCs served via `routes.json` +
the `index` generic view, using `LNbits.api.request` for authenticated API
calls. The new CRUD functions are wallet-scoped via JOIN on `mints.wallet`.

    2. `get_mint_activity(mint_id, wallet_id, limit=20)`:
    ```python
    async def get_mint_activity(
        mint_id: str, wallet_id: str, limit: int = 20
    ) -> list[dict]:
        """Return recent mint and melt records, wallet-scoped (SEC-07).

        Merges mints_records and melts tables, sorted by created_at desc.
        Each record is a dict with: type ('mint' or 'melt'), amount_msat,
        payment_hash, pr, settled (bool), created_at.
        """
        mint_records = await db.fetchall(
            "SELECT r.payment_hash, r.amount_msat, r.pr, r.minted, "
            "r.created_at, 'mint' as type "
            "FROM lnurlmint.mints_records r "
            "JOIN lnurlmint.mints m ON r.mint_id = m.id "
            "WHERE r.mint_id = :mid AND m.wallet = :wallet "
            "ORDER BY r.created_at DESC LIMIT :limit",
            {"mid": mint_id, "wallet": wallet_id, "limit": limit},
        )
        melt_records = await db.fetchall(
            "SELECT r.payment_hash, r.amount_msat, r.pr, r.settled, "
            "r.created_at, 'melt' as type "
            "FROM lnurlmint.melts r "
            "JOIN lnurlmint.mints m ON r.mint_id = m.id "
            "WHERE r.mint_id = :mid AND m.wallet = :wallet "
            "ORDER BY r.created_at DESC LIMIT :limit",
            {"mid": mint_id, "wallet": wallet_id, "limit": limit},
        )
        activity = list(mint_records) + list(melt_records)
        activity.sort(key=lambda r: r["created_at"], reverse=True)
        return activity[:limit]
    ```
