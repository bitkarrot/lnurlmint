## Phase Goal

**As a** visitor, **I want to** view a public one-pager showing the mint QR code, limits, and node info without authentication, **so that** I can scan and pay to mint a bearer note or learn about the mint's funding node.

## Acceptance Criteria

- [ ] `GET /lnurlmint/m/{mint_id}` serves the public one-pager via `index_public` (no authentication).
- [ ] The one-pager displays the mint QR code (LNURL of the payRequest) using the `lnbits-qrcode` Vue component.
- [ ] The one-pager displays mint limits: min amount (`min_mint_msat` in sats) and max amount (`max_mintable_msat` fee-aware, in sats).
- [ ] The one-pager displays node info (alias, color, pubkey, capacity, channel/peer counts) with mempool.space/amboss.space links when the funding source implements the Node API.
- [ ] The one-pager shows "Node info unavailable" when the funding source does not implement the Node API (FakeWallet, VoidWallet) or is unreachable.
- [ ] The one-pager shows the Tor address (as an alternative LNURL/QR) if `onion_url` is configured and the visitor is not already on Tor.
- [ ] The one-pager shows a sunset notice if `sunset_mint` is true (no QR code, just the notice).
- [ ] `GET /lnurlmint/api/v1/public/{mint_id}` returns JSON with: username, lnurl, min_mint_msat, max_mintable_msat, sunset_mint, onion_url, mint_pubkey, node_info (or null).
- [ ] The public API endpoint returns 404 for an unknown mint_id.
- [ ] The public API endpoint requires no authentication.
- [ ] `routes.json` includes the `/lnurlmint/m/:mint_id` route mapping to `PageLnurlmintPublic`.

## Artifacts This Phase Produces

This plan delivers the public-facing one-pager: a Vue 3 + Quasar SPA served
via `index_public` (no auth) that shows the mint QR code, limits, node info,
and Tor address. A new unauthenticated API endpoint (`GET /api/v1/public/
{mint_id}`) provides all data in a single JSON response. The SPA uses the
`lnbits-qrcode` component for QR rendering (same as giftcards' redeem page).
Node info is fetched server-side via LNbits' `get_funding_source()` +
`get_public_info()`, with graceful degradation when the Node API is not
available.

    Add the endpoint:
    ```python
    @lnurlmint_api_router.get("/public/{mint_id}")
    async def api_get_public_mint_info(mint_id: str, request: Request) -> dict:
        """Public mint info for the one-pager (no authentication).

        Returns mint metadata (username, limits, sunset, onion_url),
        the LNURL of the payRequest (bech32-encoded, Tor-aware), the
        mint's public signing key, and node info (if the funding source
        implements the Node API). Returns 404 for unknown mint_id.

        No sensitive data is exposed: no wallet_id, no mint_privkey,
        no note secrets. The mint_pubkey is the mint's public signing
        key (not a secret). Node info is already public on the LN graph.
        """
        mint = await get_mint_by_id(mint_id)
        if mint is None:
            raise HTTPException(status_code=404, detail="Mint not found")

        base = _public_base_url(request, mint)
        lnurl_url = f"{base}/lnurlmint/lnurlp/{mint_id}"
        lnurl_data = convertbits(lnurl_url.encode(), 8, 5, True)
        lnurl = bech32_encode("lnurl", lnurl_data).upper()

        # Fetch node info if the funding source implements the Node API.
        node_info = None
        try:
            funding_source = get_funding_source()
            if (funding_source.features
                    and Feature.nodemanager in funding_source.features
                    and funding_source.__node_cls__):
                node = funding_source.__node_cls__(funding_source)
                public_info = await node.get_public_info()
                node_info = {
                    "id": public_info.id,
                    "alias": public_info.alias,
                    "color": public_info.color,
                    "num_peers": public_info.num_peers,
                    "capacity_msat": public_info.channel_stats.total_capacity,
                    "num_channels": sum(
                        public_info.channel_stats.counts.values()
                    ),
                    "addresses": public_info.addresses,
                }
        except Exception:
            pass  # Graceful degradation — node_info stays null.

        return {
            "username": mint.username,
            "lnurl": lnurl,
            "min_mint_msat": mint.min_mint_msat,
            "max_mintable_msat": max_mintable_msat(mint),
            "sunset_mint": mint.sunset_mint,
            "onion_url": mint.onion_url,
            "mint_pubkey": mint_pubkey(mint),
            "node_info": node_info,
        }
    ```

    Note: The `request: Request` parameter is injected by FastAPI
    automatically — no decorator needed. The `_public_base_url` call
    uses it for Tor-aware base URL derivation (Plan 06-01).

    ```javascript
    window.PageLnurlmintPublic = {
      template: '#page-lnurlmint-public',
      data() {
        return {
          mint: null,
          loading: true,
          notFound: false,
          copied: false,
        }
      },
      computed: {
        mintId() {
          const parts = window.location.pathname.split('/')
          // /lnurlmint/m/{mint_id} → parts[3]
          return parts[parts.length - 1]
        },
        isOnion() {
          return window.location.hostname.endsWith('.onion')
        },
        showTorSection() {
          return this.mint && this.mint.onion_url && !this.isOnion
        },
        lnurlLightning() {
          if (!this.mint || !this.mint.lnurl) return ''
          return `lightning:${this.mint.lnurl}`
        },
      },
      async mounted() {
        await this.loadMintInfo()
      },
      methods: {
        async loadMintInfo() {
          this.loading = true
          try {
            const response = await fetch(
              `/lnurlmint/api/v1/public/${this.mintId}`
            )
            if (response.ok) {
              this.mint = await response.json()
            } else if (response.status === 404) {
              this.notFound = true
            }
          } catch (error) {
            console.error('Failed to load mint info:', error)
            this.notFound = true
          } finally {
            this.loading = false
          }
        },
        formatSats(msat) {
          if (!msat) return '-'
          return (msat / 1000).toLocaleString() + ' sats'
        },
        async copyLnurl() {
          if (!this.mint || !this.mint.lnurl) return
          try {
            await navigator.clipboard.writeText(this.mint.lnurl)
            this.copied = true
            setTimeout(() => { this.copied = false }, 2000)
            this.$q.notify({ type: 'positive', message: 'LNURL copied!' })
          } catch (e) {
            this.$q.notify({ type: 'negative', message: 'Failed to copy.' })
          }
        },
        async copyOnion() {
          if (!this.mint || !this.mint.onion_url) return
          try {
            await navigator.clipboard.writeText(this.mint.onion_url)
            this.$q.notify({ type: 'positive', message: 'Tor address copied!' })
          } catch (e) {
            this.$q.notify({ type: 'negative', message: 'Failed to copy.' })
          }
        },
      }
    }
    ```
