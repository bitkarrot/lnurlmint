## Phase Goal

**As a** note holder, **I want to** rotate a bearer note (burn old, mint new same value) and merge multiple notes into one (sum + fee refund), **so that** I can refresh and consolidate my bearer notes without melting them back to sats.

## Acceptance Criteria

- [ ] `crud.swap(burn_ids, mint_note_ids, mint_amounts, mint_id)` atomically burns N notes and mints M notes in one `async with db.connect() as conn:` block.
- [ ] `swap` validates ALL burn ids (not spent, not pending) and ALL mint note ids (no collision with `mints_records` or `notes`) BEFORE any mutation (validate-then-burn-then-mint).
- [ ] `swap` raises `ValueError("Invalid or already spent k1.")` on invalid/spent/duplicate burn id or collision on either table.
- [ ] `swap` raises `PendingNoteError("pending")` if any burn id is pending.
- [ ] `swap` deduplicates burn_ids (duplicate k1 in one request is rejected before validation).
- [ ] The `/w/cb` callback handles rotate: single `k1` + `h` (no `pr`, no `amount`) → `swap([note_id], [h], [note_value], mint_id)`, returns `{"status":"OK"}`.
- [ ] The `/w/cb` callback handles merge: many `k1` + `h` (no `pr`, no `amount`) → `swap(note_ids, [h], [sum + (n-1)*base_fee], mint_id)`, returns `{"status":"OK"}`.
- [ ] `h` is required when `pr` is absent and validated against `HEX32_PATTERN`; missing/invalid `h` returns `{"status":"ERROR","reason":"missing h"}`.
- [ ] Requests with more than 100 k1s are rejected with `{"status":"ERROR","reason":"Too many k1s (max 100)."}`.
- [ ] `sign_note` stub in `services.py` returns `None` (callable without error; Phase 5 implements real signing).
- [ ] Rotate is value-neutral (new note has same value as old); merge refunds `(n-1) * base_fee_msat`.
- [ ] No logger call includes k1, h, pr, h2, or any query string (SEC-05).

## Artifacts This Phase Produces

The `sign_note` stub is added here so the callback can call it without import errors; Phase 5 implements real signing. The callback's "not yet implemented" stub is replaced with real rotate/merge branches; split is added in Plan 02.

       # --- Rotate/merge branch (pr is None, h is present) ---
       note_ids: list[str] = []
       values: list[int] = []
       for note_k1 in k1:
           if not HEX32_PATTERN.match(note_k1):
               return {"status": "ERROR", "reason": "Invalid or already spent k1."}
           note_id = sha256(bytes.fromhex(note_k1)).hexdigest()
           note = await get_note(note_id, mint_id)

           if note.pending:
               return {"status": "ERROR", "reason": "pending"}

           values.append(note.amount_msat)

       refund = (len(note_ids) - 1) * mint.base_fee_msat

           return {"status": "ERROR", "reason": str(exc)}

       return {"status": "OK"}
