## Artifacts This Phase Produces

This plan delivers sunset mode gating for the split branch (completing ECON-05) and the two remaining critical PoC test suites (TEST-06 fee conservation, TEST-08 collision griefing). The fee conservation PoC is a white-box `Ledger` that drives rotate/split/merge/melt operations and asserts the conservation identity after each — it's the inflation hunt that proves no fee arithmetic allows attacker gain. The collision griefing PoC proves `swap` checks both `mints_records` and `notes` for collisions, preventing the A1 pending-mint squat attack. The `fresh_secret()` helper is added to `conftest.py` for use by all three test suites.
